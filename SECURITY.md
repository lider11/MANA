# Seguridad y confidencialidad

Este repositorio es público. No almacenar aquí documentos confidenciales, datos personales de beneficiarios o inversionistas, contratos privados, credenciales, claves API o configuraciones con secretos.

- Guardar secretos solo en gestores seguros y variables protegidas.
- Mantener trazabilidad de cambios y controles de acceso.
- Usar datos ficticios o anonimizados en ejemplos y pruebas.
- Revisar protección de datos, propiedad intelectual y regulación aplicable antes de publicar servicios.
- Reportar posibles vulnerabilidades por un canal privado acordado con la administración; no exponer detalles sensibles mediante issues públicos.
